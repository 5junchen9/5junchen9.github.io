# Juncheng Wu Personal Homepage

这是 `5junchen9.github.io` 的个人主页草稿，可直接用于 GitHub Pages。

## 部署方式

1. 登录 GitHub。
2. 新建仓库，仓库名必须是：

   ```text
   5junchen9.github.io
   ```

3. 把本文件夹里的 `index.html`、`styles.css`、`README.md` 上传到这个仓库根目录。
4. 打开仓库的 `Settings` -> `Pages`。
5. 在 `Build and deployment` 中选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. 保存后等待 1 到 3 分钟，访问：

   ```text
   https://5junchen9.github.io/
   ```

## 后续替换内容

- `index.html` 里替换个人介绍、项目标题和项目链接。
- `styles.css` 里调整颜色、字号和版式。
- 如果有公开仓库，可以把项目占位改成真实仓库入口。
